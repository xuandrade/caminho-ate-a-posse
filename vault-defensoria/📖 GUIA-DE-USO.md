## 🚀 PRIMEIROS PASSOS

### 1. Ativar o CSS

1. Pressione `Ctrl + ,` (Configurações)
2. Vá em `Appearance` (Aparência)
3. Role até `CSS Snippets`
4. Ative **vade-mecum-premium**
5. A vault ficará linda! 🎨

### 2. Instalar Plugin DataView

1. `Settings` → `Community Plugins` → `Browse`
2. Busque "**Dataview**"
3. Instale e ative
4. Dashboard funcionará! 📊

### 3. Importar Flashcards do Anki

1. Abra `anki-to-obsidian-converter.html` no navegador
2. No Anki: `File` → `Export` → `Notes in Plain Text (.txt)`
3. Arraste o arquivo para o conversor
4. Baixe o ZIP
5. Extraia em `02-Flashcards-Anki/`
