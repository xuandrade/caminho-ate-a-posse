# 🌸 VADE MECUM DIGITAL PREMIUM - DEFENSORIA PÚBLICA

*Sistema completo de estudos personalizado para concurso de Defensoria Pública*

## ✨ O QUE É ESTE SISTEMA?

Um **Vade Mecum Digital** completamente customizado com:

- 📚 **Formatação visual premium** (cores, ícones, boxes)
- 🎴 **Integração com Anki** (seus flashcards)
- 🧠 **TDAH-Friendly** (organização visual clara)
- 🎨 **Design chic e feminino** (rosa, lavanda, cores suaves)
- 📊 **Dashboard interativo** com progresso em tempo real
- 🔗 **Vinculação automática** entre artigos, cards e jurisprudência
- ⚡ **Rápido e offline** (tudo no seu PC, zero lag)

## 🚀 INSTALAÇÃO RÁPIDA

1. Baixe e instale o Obsidian: https://obsidian.md
2. Abra o Obsidian
3. Clique em "Open folder as vault"
4. Selecione esta pasta (vault-defensoria)
5. Pressione `Ctrl + ,` → Appearance → CSS Snippets → Ative "vade-mecum-premium"
6. Instale o plugin "Dataview": Settings → Community Plugins → Browse → Dataview
7. Abra o 📊 DASHBOARD.md
